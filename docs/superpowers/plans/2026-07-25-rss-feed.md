# Flux RSS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `/rss.xml` endpoint that publishes a combined RSS 2.0 feed of blog posts and curated resources, with an autodiscovery `<link>` tag in every page's `<head>`.

**Architecture:** A new Astro API route (`src/pages/rss.xml.ts`) built with the official `@astrojs/rss` package. It reads the existing `posts` and `ressources` content collections via `getCollection`, maps each entry to a feed item (posts link to their own page on this site; resources link to their external `link` field, falling back to `/ressources` if absent), merges both lists, sorts by date descending, and returns the generated feed. `Layout.astro` gets one extra `<link rel="alternate" type="application/rss+xml">` tag next to the existing sitemap link, so feed readers and browsers can discover it automatically.

**Tech Stack:** Astro 5 API routes, `@astrojs/rss` (new dependency), existing `astro:content` collections (`posts`, `ressources`) defined in `src/content/config.ts`.

## Global Constraints

- Feed items use **excerpt/description only** — never the full `content`/`processedContent` HTML body. This keeps the feed lightweight and consistent with the site's existing pattern of driving readers back to the article page.
- Site base URL comes from `astro.config.mjs` (`site: "https://julienbruneel.fr"`, `trailingSlash: "never"`) — reuse Astro's injected `site` context, never hardcode the domain.
- Follow the existing manual-XML-route convention already used by `src/pages/sitemap.xml.ts` and `src/pages/robots.txt.ts` (plain `APIRoute`, no test framework in this repo — verification is manual build + `curl`, not unit tests).
- French language, consistent tone with existing site copy (see `ressources.astro`, `Layout.astro` defaults) for any user-facing text (feed title/description).

### Task 2: Create the combined `/rss.xml` feed route

**Files:**
- Create: `src/pages/rss.xml.ts`

**Interfaces:**
- Consumes:
  - `getCollection("posts")` → entries typed `CollectionEntry<"posts">`, `data` shaped per `postOutputSchema` (`src/content/schemas/posts.schema.ts:40-60`): `title: string`, `slug: string`, `excerpt: string`, `publishedDate: Date`, `modifiedDate: Date`.
  - `getCollection("ressources")` → entries typed `CollectionEntry<"ressources">`, `data` shaped per `ressourceOutputSchema` (`src/content/schemas/ressources.schema.ts:28-41`): `title: string`, `slug: string`, `description: string`, `link: string | null`, `publishedAt: Date`.
  - `rss` default export from `@astrojs/rss`, signature `rss(options: { title, description, site, items, ... }): Response`.
- Produces: `GET` handler at route `/rss.xml`, returning `Response` with `Content-Type: application/xml`. No other task depends on this file's internals, only on the route existing at `/rss.xml`.

- [ ] **Step 1: Write the route**

```typescript
// src/pages/rss.xml.ts
import rss from "@astrojs/rss";
import type { APIRoute } from "astro";
import { getCollection } from "astro:content";

export const GET: APIRoute = async ({ site }) => {
  const [posts, ressources] = await Promise.all([
    getCollection("posts"),
    getCollection("ressources"),
  ]);

  const postItems = posts.map((post) => ({
    title: post.data.title,
    description: post.data.excerpt,
    pubDate: post.data.publishedDate,
    link: `/${post.data.slug}`,
  }));

  const ressourceItems = ressources.map((ressource) => ({
    title: ressource.data.title,
    description: ressource.data.description,
    pubDate: ressource.data.publishedAt,
    link: ressource.data.link ?? "/ressources",
  }));

  const items = [...postItems, ...ressourceItems].sort(
    (a, b) => b.pubDate.getTime() - a.pubDate.getTime(),
  );

  return rss({
    title: "Julien Bruneel - Développeur web",
    description:
      "Articles, tutoriels et ressources sur le développement web.",
    site: site!,
    items,
    trailingSlash: false,
  });
};
```
